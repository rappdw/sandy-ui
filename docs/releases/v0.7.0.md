**Debt + daily-driver polish** — the first milestone on the road to 1.0 (see ROADMAP_1.0.md): four fixes that make daemon-era daily use honest, a live mouse-mode toggle, and — the quiet headline — the daemon lifecycle finally has integration-test coverage, no Docker required.

## What's new

### Fixes

- **`sandy.launchCommand` now composes with daemon mode** (#24). With persistence on, the override was silently ignored — the daemon path never consulted it. An explicit override now forces the legacy lifecycle (documented in the setting), and the capability probe is skipped entirely when it's set.
- **Secrets can finally be cleared from the settings UI** (#25). Blank still means "keep current"; a new per-field clear/undo toggle marks a stored secret for deletion on save. Host-side, only schema-verified secret-tier keys are deletable through this channel — a hostile webview message can't remove arbitrary config keys.
- **No more blank settings panel while sandy answers `--print-schema`** (#25) — an immediate loading state, and when the bundled mock schema is in play (sandy unreachable) the panel now says so loudly instead of silently rendering possibly-wrong fields.

### Session hygiene (the flip side of persistence)

- **Session age is visible** (#26): tree rows show `persisted (N clients) · up 3d`, tooltips carry the since-timestamp, and the status-bar tooltip ages its persisted entries.
- **Long-runner nudge**: once per window, sessions running longer than `sandy.longRunningSessionHours` (default 24h, 0 disables) surface a notification with Attach/Stop actions — forgotten sessions no longer accumulate invisibly.

### Terminal

- **`sandy.terminal.mouseMode`** (#29): `nativeSelection` (default, today's behavior) or `tmux` — hand the mouse back to tmux for in-app clicks and pane interactions, at the cost of ⌥-drag for selection. The switch applies **live**: the bridge replays the intercepted mouse-tracking state into (or out of) xterm on toggle, so it takes effect immediately instead of waiting for tmux to renegotiate.

### Test infrastructure (#27)

- **`test/fixtures/fake-sandy`** — a dependency-free bash double implementing sandy 1.1.0's frozen daemon contract (exit codes, `--print-state` shapes, control-file-driven attach lifecycle), with its output pinned against the *production* parsers by a vitest suite that runs anywhere.
- **`test/integration/daemon.test.ts`** — the full lifecycle under a real VSCode: two-phase launch, tab-close-detaches, relaunch-reattaches, explicit stop, plus the `launchCommand` and `persistSessions:false` legacy fallbacks. Runs in CI on Linux and macOS; no Docker, no real sandy.
- Suite totals: 196 unit tests (+38 this release) + 6 daemon integration scenarios.

## Install

```bash
curl -L https://github.com/rappdw/sandy-ui/releases/download/v0.7.0/sandy-ui-0.7.0.vsix -o /tmp/sandy.vsix
code --install-extension /tmp/sandy.vsix
```

Then Cmd+Shift+P → "Developer: Reload Window".
