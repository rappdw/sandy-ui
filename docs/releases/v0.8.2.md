**Finding the right window** — a papercut fix for anyone running sandy in a dozen VSCode windows at once.

## What's new

### The tab title leads with the workspace, not the pid

Sandy tabs were titled `Sandy (attached pid=12345)`. VSCode's default `window.title` is `${activeEditorShort}${separator}${rootName}`, so that string is also the *leading* text of the OS window title — and macOS sorts its Window menu alphabetically by it. The practical effect: with many sandy windows open, the Window menu was sorted **by process id**, with the workspace name stranded at the end where it could do no sorting work.

Titles are now `<workspace> · Sandy`, with the state appended when it's worth saying (`(starting…)`, `(detached)`, `(exit 6)`). The tab says which project it is, and the Window menu comes out alphabetical by workspace for free. The pid still goes to the "Sandy" output channel.

Two details that had to change with it:

- An **OSC-0 title** emitted from inside the terminal used to overwrite the whole title and lose the workspace. It's now a detail — `<workspace> · claude`.
- The **unseen-activity badge** used to prepend `● `, which would have clustered every busy window under a single character and undone the sort. It now sits after the workspace: `<workspace> · ● Sandy`.

Both fell out of the old code string-patching `panel.title`; every title now routes through one pure, unit-tested function.

### Status-bar quick-pick is sorted

Clicking the status-bar item lists your live sessions. It already led each entry with the workspace basename, but emitted them in insertion order — local sessions first, then persisted. It's now one alphabetical list, since finding a workspace among many is the entire point of that picker. The icon and detail still distinguish attached / detached / persisted.

## Also worth knowing

If you want *every* VSCode window sorted by workspace — including ones with no sandy session — that's a user setting rather than an extension change:

```jsonc
"window.title": "${rootName}${separator}${activeEditorShort}"
```

This release makes sandy windows sort correctly without it.

## Install

```bash
curl -L https://github.com/rappdw/sandy-ui/releases/download/v0.8.2/sandy-ui-0.8.2.vsix -o /tmp/sandy.vsix
code --install-extension /tmp/sandy.vsix
```

Then Cmd+Shift+P → "Developer: Reload Window".
