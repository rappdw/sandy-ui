**First real release** after the post-spike 0.0.1 dogfooding period.

## What's new

- **Real sandy introspection** — `--print-schema` drives the settings webview (cached by sandy version), `--print-state` polled every 5s populates the projects tree with live state badges, `--validate-config` triggers the pre-flight approval modal when a workspace has unapproved privileged keys
- **Webview code is TypeScript** — both terminal and settings webviews compile via esbuild; catches the silent-runtime-error class that bit twice during the spike
- **120 unit tests** across pure-logic modules (OSC parsers, configIO, lock sweep, schema parser, state badges, sandbox deletion, sandy-path resolver)
- **Tree right-click menu** — Launch, Open Workspace (this/new window), Reveal in Finder, Copy Path, Remove Lock, Delete Sandbox (with safety-checked rm)
- **Workspace-aware launch** — clicking a tree item for a different workspace opens the folder + auto-launches sandy after VSCode reactivates
- **Graceful container shutdown** on `Cmd+Q` — `deactivate()` parallel-SIGINTs all live PTYs and waits for their cleanup traps before returning
- **`sandy.binaryPath` setting + common-location resolver** — finds sandy even when VSCode is launched from the Dock (narrower PATH than your shell)
- **Project / Global scope tabs** in the settings webview, scope-aware secrets, full env-var inventory
- **Pre-flight approval modal** renders raw `KEY=VALUE` content verbatim
- **Polish**: panel auto-close on launch, xterm refit on tab visibility-restore, stale-lock auto-sweep, beach activity-bar icon

## Still pre-distribution

Not yet on Marketplace / OpenVSX. Two gates remain (see SPEC_SANDY_UI.md): macOS TCC bundle-ID attribution mitigation, and node-pty cross-platform packaging story.

## Install

Side-load via the attached `.vsix`:

```bash
curl -L https://github.com/rappdw/sandy-ui/releases/download/v0.1.0/sandy-ui-0.1.0.vsix -o /tmp/sandy.vsix
code --install-extension /tmp/sandy.vsix
```

Then Cmd+Shift+P → "Developer: Reload Window".
